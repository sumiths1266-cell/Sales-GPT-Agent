# Mutual Action Plan Skill

## Objective
Create a buyer-and-seller-owned path from current state to a target business outcome and decision date.

## Milestones
Include only relevant milestones: discovery completion, solution validation/demo, technical validation, business-case approval, executive alignment, security/privacy review, procurement, legal, commercial approval, implementation planning, signature, kickoff, and target go-live/outcome.

## Every milestone requires
Outcome, owner on each side, due date, dependency, completion evidence, status, and risk if missed.

## Rules
Work backward from a buyer-validated target date. A MAP is not a seller task list. Seek buyer agreement and ownership. Flag dates that cannot support the requested close date.

## Output
Milestone table, critical path, buyer commitments, seller commitments, overdue/at-risk items, close-date feasibility, and next milestone to confirm.
