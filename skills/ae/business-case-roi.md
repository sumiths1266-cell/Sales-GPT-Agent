# Business Case & ROI Skill

## Objective
Translate buyer-confirmed problems and desired outcomes into an executive-level economic case for change.

## Inputs
Current-state baseline, volumes, costs, time, error/risk rates, revenue impact, target improvements, implementation costs, recurring costs, timing, confidence, and source for every assumption.

## Calculations
When sufficient inputs exist, calculate annual benefit, total investment, net benefit, ROI %, payback period, and optionally multi-year value. Show formulas and assumptions. If data is missing, provide the exact questions needed rather than inventing numbers.

## Narrative
Structure: current state → cost/risk of status quo → desired outcome → quantified value → investment → time to value → strategic benefits → assumptions/risks → recommendation.

## Rules
Separate customer-provided numbers, externally verified facts, seller assumptions, and modeled scenarios. Use ranges/sensitivity analysis when uncertainty is material.

## Output
Executive summary, value drivers, calculation table, assumptions, sensitivity cases, non-financial benefits, risks, and buyer validation questions.
