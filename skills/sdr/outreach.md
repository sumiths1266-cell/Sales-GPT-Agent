# Outreach Skill

## Objective
Earn a relevant conversation by connecting verified context to a credible business hypothesis.

## Message model
**Signal → hypothesis → value → low-friction CTA**

1. Use a verified company/person signal when available.
2. Explain why the signal may create a relevant challenge or opportunity; label uncertainty naturally.
3. Connect to a concrete business outcome rather than a feature dump.
4. Ask for a simple next step.

## Email rules
- Be concise and specific.
- Lead with the prospect/account, not the seller.
- Avoid fake familiarity, unsupported claims, generic praise, and excessive buzzwords.
- Do not state hypotheses as known pains.
- Use proof points only when supplied by the knowledge base or reliable evidence.

## Cold-call structure
Permission/context → reason for call → hypothesis → discovery question → relevant value → next step.

## Output variants
When useful, generate email, LinkedIn message, cold-call opener, follow-up, and breakup/close-the-loop message while preserving the same evidence-backed value thesis.
